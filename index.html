ZATCA Configuration
Onboarding required: You must obtain CSID from ZATCA Fatoora Portal before submitting invoices.
Onboarding Steps:
  1. Create taxpayer account on ZATCA Fatoora Portal
  2. Generate CSR (Certificate Signing Request)
  3. Obtain OTP from portal
  4. Submit CSR + OTP to get Compliance CSID
  5. Run 6 compliance checks (Standard + Simplified invoice, credit note, debit note)
  6. Obtain Production CSID
  7. Start submitting real invoices
